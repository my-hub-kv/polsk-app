# Contributing

Read [AGENTS.md](AGENTS.md) and the relevant documentation before starting. Work from a bounded issue, use a non-main branch, make small reviewable PRs, and update tests and documentation with the change.

Visible text is Danish; technical code and documentation are English. Use synthetic data only. Do not commit secrets or real participant information. Dependencies and destructive migrations need explicit approval; human review is required. Follow the [pull-request process](docs/development/pull-request-process.md) and [Code of Conduct](CODE_OF_CONDUCT.md).
