# Delivery checklist

- Acceptance criteria map to code and tests.
- Event-year scoping and object authorization are server-side.
- Acting account and active participant are distinct where relevant.
- Fixtures/UI evidence are synthetic, Danish, accessible, and mobile-aware.
- Migrations, query efficiency, errors, and documentation are reviewed.
- No secrets, provider details, unsupported claims, or unclean diff.
- Tests were actually run and results reported.
