# Polsk App

Polsk App is an early-development, invitation-only coordination application for one recurring annual family event. Its participant interface is Danish. The source is licensed under AGPL-3.0.

The product is a modular Django monolith with a PostgreSQL datastore and server-rendered interface. Read the [documentation index](docs/index.md), [local setup](docs/development/setup.md), and [contributing guide](CONTRIBUTING.md) before working on it.

Never put real event data, participant information, credentials, or private operational details in issues, fixtures, screenshots, examples, or committed files.
