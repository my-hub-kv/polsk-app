# ADR 0006: Explainable planning rules

Status: Accepted
Date: 2026-07-24

## Context

Chore and shopping suggestions affect people and require trust.

## Decision

Use explainable rules with human review, not opaque machine learning. A later constraint solver must preserve explainability and tests.

## Consequences

Suggestions expose reasons and remain editable.

## Alternatives considered

Opaque automatic decision-making was rejected.
