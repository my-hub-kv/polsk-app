# Deletion and history

Participant deletion removes or anonymises credentials, reset data, relevant invitations, phone, dietary data, preferences, push subscriptions, email, household access, and current personal settings.

For chores, shopping actions, stock corrections, retained messages, and audits, choose explicit domain behaviour: delete records with no shared value, null a participant reference where history matters, and render “Deleted participant” without copying sensitive attributes into audit text. Never cascade-delete an event year or household. Service/admin tests must cover deletion impact.
