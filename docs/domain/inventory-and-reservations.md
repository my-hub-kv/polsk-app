# Inventory and reservations

**Product rules: Confirmed. Domain design: Candidate. Implementation: Planned.**

Concepts include product, unit, category, storage location, approximate stock state, optional verified quantity, stock observation, missing report, reservation, dinner box/named purpose, delivery receipt status without image, and verification actor/time.

Keep useful verified-observation history without a consumption ledger. Derive total known, reserved, and generally available amounts; show an approximate state when precision is unavailable. An adult missing report is immediately visible but distinct from verified count; an authorised coordinator can reverse it.
