# Glossary

| Term | Meaning |
| --- | --- |
| Event series / event year | The recurring event and one separately scoped annual occurrence. |
| Participant / login account | Real-world profile / authentication identity; they are separate. |
| Active participant / acting account | Profile being represented / authenticated account performing the action. |
| Household | Related participants eligible for bounded profile switching. |
| `A`, `X`, `B`, `BA` | Chore roles: responsible, adult, child, dinner child-food responsible. |
| Sticky / locked assignment | Planner-preserved assignment / assignment not changed by planning. |
| Workload percentage | Relative target share of chores. |
| Day responsible | Person derived from the following day’s dinner `A`. |
| Public / official / private channel | Discoverable / mandated / member-only communication channel. |
| Basic / reserved food | General stock / stock allocated to a purpose or dinner box. |
| Stock observation / missing report | Verified stock information / participant report awaiting verification. |
| Shopping request / list / vendor export | Requested item / coordinator working list / CSV snapshot for a vendor. |
| Forecast snapshot / observed weather | Forecast captured at a time / actual historical weather. |
